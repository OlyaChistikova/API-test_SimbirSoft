# API Project

Данный проект представляет собой API для управления сущностями, реализованный на Java. В проекте включает пять тестов, которые демонстрируют основные операции с сущностями: создание, получение, обновление и удаление.

## Описание функций

1. Создание сущности: Создает новую сущность с заданными параметрами.
2. Получение сущности по ID: Позволяет получить детальную информацию о сущности по ее уникальному идентификатору.
3. Получение всех сущностей: Возвращает список всех сущностей в системе.
4. Обновление сущности: Позволяет обновлять информацию о сущности по ее ID.
5. Удаление сущности: Удаляет сущность из системы по ее ID.

## Установка и запуск

### Предварительные требования

- Установленный [Docker Desktop](https://www.docker.com/products/docker-desktop) на вашем компьютере.

## Запуск тестов 

- tests_default - mvn clean test -P tests_default
- tests_default_parallel - mvn clean test -P tests_default_parallel

## Запуск allure отчётов

- allure serve

### Запуск проекта

HOST http://localhost:8080

SWAGGER документация http://localhost:8080/api/_/docs/swagger/
